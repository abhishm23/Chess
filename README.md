# Chess Tactics Trainer & Interactive Puzzle Engine

Modern, interactive chess learning and tactical puzzle application engineered with React 18, Vite, TypeScript, Tailwind CSS, and Vitest.

## Features
- **Tactical Puzzle Trainer**: Interactive board with legal move validation and dynamic evaluation.
- **Analysis Board & Game Tree**: Branching move trees, FEN/PGN import and export.
- **Battle-Tested Engine**: Comprehensive unit and integration test coverage using Vitest.

## Tech Stack
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS
- **Testing**: Vitest, React Testing Library
- **Orchestration**: Python automation runners (`run.py`, `run.bat`)

## Development & Testing
```bash
# Run tests
npm test

# Launch development server
npm run dev
```
